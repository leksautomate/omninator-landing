# Omninator Landing Page

Marketing site for **Omninator**, a Chrome extension that batch-automates AI image and video
generation in Google Flow.

Static HTML/CSS, no build step or dependencies — just open `index.html`, or serve the folder with
any static host (e.g. GitHub Pages).

## Pages

- `index.html` — home (features, how it works, pricing, FAQ, terms)
- `guide.html` — prompt & tag syntax guide
- `releases.html` — what's shipped / planned
- `privacy.html` — privacy policy
- `refund.html` — refund policy

## Pricing

Preview pricing only — checkout isn't wired up yet: Monthly $2, Yearly $20, Lifetime $49 (one-time).

## Publishing with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
